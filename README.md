# Northstar SOC

A browser-based SOC analyst practice workspace. Work through fictional incident scenarios, make triage decisions, and receive feedback, alongside a sample alert queue and investigation dashboard.

## Run locally

Open `index.html` in a modern browser. The demo has no build step, backend, or package installation.

## Workspace features

- Three guided identity, endpoint, and cloud-identity scenarios with decision points, immediate explanations, scoring, and replay.
- Prioritized alert queue with severity and status filters, search, and keyboard row selection.
- Investigation detail panel with entity context, MITRE ATT&CK tactics, and an event timeline.
- Analyst actions to assign, investigate, resolve, and reopen sample alerts.
- Security posture metrics, UTC clock, detection activity chart, and team activity feed.
- Responsive layout for desktop and smaller screens.

The practice lab and dashboard use fictional sample data. Scenario scores and alert changes exist only in the current page session. This is a safe interface exercise, not a real SIEM, endpoint lab, or production response tool; it does not connect to real systems or execute security actions.
